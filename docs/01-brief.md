Create an app to view diffs in a local Git repository.

## Requirements

- Support Linux, Windows and macOS
- View only
- Select the uncommitted changes to view their diff against the last commit.
- Can select 2 commits with Cmd/Ctrl+Click to see the diff between the two commits.
- Can also select the uncommitted changes together with another commit to view the diff.
- Show the uncommitted changes as just the last node in the Git history.
- Implement it with panels like in docs/01-sourcetree-cropped.png - commit history tree viewer, changed files, commit metadata and message, diff view.
